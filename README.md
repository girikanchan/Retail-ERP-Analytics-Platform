Retail ERP Analytics Platform  |  MySQL · Microsoft Fabric · PySpark · Power BI

Problem:  Small and mid-size retailers lose 10-15% of revenue annually to 
          stockouts, overstock, and undetected margin erosion — driven by 
          disconnected systems and no real-time visibility.

Solution: Built a full-stack retail ERP with an integrated analytics platform:
  • Transactional layer — 30-table MySQL schema covering inventory, procurement (3-way match), POS billing, and GST compliance
  • Data Engineering — Medallion architecture on Microsoft Fabric (Bronze/Silver/Gold) with PySpark ETL pipelines transforming raw ERP data into analytics-ready datasets
  • Intelligence layer — Demand forecasting, supplier scorecards, margin erosion alerts, and inventory health scoring
  • BI layer — Power BI dashboard with 5 report pages covering inventory health, supplier performance, sales & margin, AP aging, and regional trends# Retail-ERP-Analytics-Platform
